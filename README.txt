測量士・測量士補 過去問マスター Ver.5

1. ZIPをすべて展開してください。
2. フォルダ内の index.html をChromeまたはEdgeで開いてください。
3. 年度と試験区分を選んでください。測量士では午後記述式も選べます。
4. 問題文・図表はアプリ内に表示されます。PDFを開く必要はありません。
5. 公式正答は各資格・各年度28問ずつ収録しています。

注意：午前の問題番号からページへの初期位置は推定です。前後ページのボタンで確認してください。
午後は公式解答例を見比べる方式です。記述式の自動採点はありません。
独自の詳しい解説や分野別分類は未収録です。
学習履歴はブラウザのlocalStorageに保存され、ブラウザデータ削除で消える場合があります。
このアプリはインターネット接続不要ですが、スマホで使う場合はフォルダ一式をWebサーバーに公開する必要があります。
